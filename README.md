## 👤Intro
**팀 내 코드 리뷰를 주도하며** 단순히 코드 오류를 확인하는 데 그치지 않고, 구현 의도와 개선 방향을 함께 논의하는 지식 공유의 장으로 운영했습니다.

예를 들어, 중복된 비즈니스 로직과 가독성이 떨어지는 메서드 구조에 대해 공통 컨벤션을 제안하고, 메서드 분리·변수명 개선·주석 보완 등의 리팩토링을 진행했습니다.

그 결과 팀원들이 코드 흐름을 빠르게 이해할 수 있었고, 이후 기능 추가 및 수정 과정에서도 커뮤니케이션 비용과 오류 발생을 줄일 수 있었습니다.

이러한 경험을 통해 **코드 품질은 개인의 역량을 넘어 팀의 협업 방식에서 완성된다는 것**을 체감했으며, 앞으로도 **적극적인 소통과 코드 리뷰를 통해 팀의 생산성과 프로젝트 완성도를 함께 높이는 개발자**로 기여하고자 합니다.
